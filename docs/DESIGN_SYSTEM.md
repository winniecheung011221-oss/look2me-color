# V7 视觉设计

用美妆编辑台的色粉、半透薄膜和色带作为视觉语汇。首页以流动色粉场和超大中文标题开场，问答让色彩反馈用户的选择，进入档案和工作台后降低背景饱和度。

| Token | 值 |
|---|---|
| 纸面 | #F5F0EB |
| 墨色 | #241D2C |
| 葡萄紫 | #5D3E72 |
| 玫瑰色 | #B2768F |
| 杏色 | #F4C295 |
| 冰青 | #B9DEDC |

标题采用系统中文黑体，英文以 Georgia 作编辑式对照，正文 15–17px。上传块用半透明圆面，问答胶囊用明确选中描边，结果采用横向照片比较与带可点击色块的工具栏。桌面三列工作台，移动按照片、选妆、编辑的阅读顺序落位。渐变色块使用缓慢位移，用户开启减少动态效果后静止。

评审修订方向：流动视觉集中于首页与问答。档案以色带和采样依据分层，排除通用的等尺寸统计卡片。妆容选择以四个可筛选系列服务 16 种选择，图片和色值标记各自版本。
